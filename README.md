# 🎨 Background Color Changer

A simple Background Color Changer built using **HTML** and **JavaScript**. This project changes the background color of the webpage each time the user clicks the **Change Color** button.

## Features

* Change the background color with one click
* Random color generation
* Simple and easy-to-use interface
* Beginner-friendly JavaScript project

## Technologies Used

* HTML
* JavaScript

## How to Run

1. Download or clone the repository.
2. Open the `index.html` file in your browser.
3. Click the **Change Color** button to change the background color.
